# Removed talents

Talents that appear somewhere in the git history (all branches, all commits) but no longer exist anywhere in the current talent files (`staging`). A talent counts as removed when its **name** is absent from every class and spec today, so a renamed or typo-fixed talent shows up here under its old name. For each talent the most recent version before removal is shown; the class and spec are where it last lived.
